# Eink photo frame

## Installation


1. Get arduino
2. Add Seeed library
3. Put board into bootloader mode (double click reset)
4. Push to board in arduino

5. Get your image: 
```bash
uv run spectra6_converter.py ../../images/800x480.jpg -o my_image.h --preview preview.png
```
